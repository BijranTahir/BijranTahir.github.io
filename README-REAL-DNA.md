# Real DNA hero upgrade

This version replaces the `DNA × DATA` text/orbit placeholder with a recognizable
animated DNA double helix built directly into the website.

Features:
- two DNA backbones
- base-pair rungs
- glowing molecular nodes
- orbiting molecular particles
- continuous 3D-style rotation
- liquid background remains behind the DNA
- mobile responsive
- reduced-motion accessibility
