# Tahir Ahmad Bijran — Scientific Workspace V10

Dark-only public scientific portfolio and browser-based workspace.

## Included
- Research dashboard, research areas and progress
- Research Idea Vault
- Digital laboratory and experiment records
- Local digital lab notebook and scientific journal
- Literature and publication library
- BioTools: sequence analysis, GC%, reverse complement, translation, basic mass estimate
- Scientific Data Studio with CSV/TSV parsing and plotting
- Computational biology workflow builder
- Microscopy image viewer from local files
- Visualization Studio
- Skills/evidence, inventory and analytics
- Knowledge graph
- Academic CV print/export
- Documentation and changelog
- Global search / command palette
- Mobile scrolling navigation
- Dark-only PWA shell
- Existing Admin Control Center and JSON content collections

## Public repository rule
This repository is public. Never place tokens, passwords, API keys, unpublished raw research data or confidential documents in the public repository. Local workspace entries use browser localStorage.
