# Actual 3D DNA website

This version does NOT use a generated image for the DNA.

The hero uses a real-time WebGL/Three.js model:
- two 3D helical backbones
- 34 physical base-pair rungs
- atom-like nodes
- molecular clusters
- floating particles
- lighting and depth
- continuous rotation
- subtle pointer interaction
- mobile optimization

Three.js is loaded from jsDelivr at runtime.
