# Tahir Ahmad Bijran — Personal Website

## Easy content workflow
- Edit `data/research.json`, `data/projects.json`, `data/library.json`, or `data/timeline.json` to change text.
- Put PDFs/DOCX/PPTX in `assets/documents/` or `assets/presentations/`.
- Put images in `assets/images/` and videos in `assets/videos/`.
- For a new library item, add an object to `data/library.json` with `title`, `description`, `type`, and `file`.
